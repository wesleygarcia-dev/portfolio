01

Sobre o Projeto

O Sistema de Análise de Mensagens foi desenvolvido em Java com o objetivo de identificar possíveis sinais de golpes em mensagens recebidas.

O sistema compara a mensagem recebida com uma lista de palavras e expressões consideradas suspeitas. Cada termo possui um peso diferente de acordo com seu nível de risco.

Ao final, os pesos encontrados são somados e o sistema apresenta uma classificação baseada na pontuação total.
