### Projetos apresentados

#### 1. Sistema de Análise de Mensagens
Projeto criado para identificar sinais de mensagens suspeitas por meio de palavras e expressões de risco associadas a um sistema de pontuação. A versão original foi desenvolvida em Java e o portfólio inclui uma demonstração web interativa.

**Conceitos:** lógica de programação, condicionais, estruturas de repetição, arrays, objetos e sistema de pesos.

#### 2. Controle de Gastos com PostgreSQL
Banco de dados para registrar, organizar e consultar gastos de diferentes usuários, utilizando relacionamento entre tabelas e consultas SQL.

**Conceitos:** PostgreSQL, SQL, chaves primárias e estrangeiras, JOIN, filtros, agrupamentos e funções de agregação.

#### 3. Portfólio Web
Desenvolvimento do próprio portfólio utilizando HTML e CSS, com foco em estrutura, estilização, responsividade e apresentação de projetos.
