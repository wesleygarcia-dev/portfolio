01

Sobre o Projeto

O projeto foi desenvolvido utilizando PostgreSQL com o objetivo de criar um banco de dados para registrar e organizar gastos.

Cada gasto pertence a um usuário e possui informações como categoria, item, valor, quantidade, data e forma de pagamento.

Também foram desenvolvidas consultas SQL para buscar, filtrar, agrupar e calcular informações armazenadas no banco de dados.

BANCO PostgreSQL
TIPO Controle de gastos
TABELAS 2 tabelas
STATUS Concluído

02

Estrutura do Banco

usuarios

id PK · SERIAL
nome VARCHAR(100)
1
N

gastos

id PK · SERIAL
usuario_id FK · INTEGER
categoria VARCHAR(100)
item VARCHAR(100)
valor DECIMAL(10,2)
quantidade INTEGER
data DATE
forma_pagamento VARCHAR(100)

Relacionamento

A coluna usuario_id da tabela gastos referencia o id da tabela usuarios.

Dessa forma, um usuário pode possuir vários gastos cadastrados no banco.

03

Consultas SQL

01

Visualizar gastos

``` 
SELECT
    usuarios.nome,
    gastos.*
FROM gastos
JOIN usuarios
ON gastos.usuario_id = usuarios.id;
```
02

Total de gastos

``` 
SELECT
    SUM(g.valor) AS total_gasto
FROM gastos g;
```
03

Gastos por categoria

``` 
SELECT
    g.categoria,
    SUM(g.valor) AS total
FROM gastos g
GROUP BY g.categoria;
```
04

Gastos por usuário

``` 
SELECT
    u.nome,
    SUM(g.valor) AS total_gasto
FROM gastos g
JOIN usuarios u
ON g.usuario_id = u.id
GROUP BY u.nome;
```
05

Filtro por data

``` 
SELECT
    u.nome,
    g.categoria,
    g.item,
    g.valor,
    g.data
FROM gastos g
JOIN usuarios u
ON g.usuario_id = u.id
WHERE g.data >= '2026-06-12';
```
06

Buscar usuário

``` 
SELECT
    u.nome,
    g.item,
    g.categoria,
    g.valor
FROM gastos g
JOIN usuarios u
ON g.usuario_id = u.id
WHERE u.nome = 'Gabriel';
```
